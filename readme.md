# 🏦 POOBank — Finance CLI

Aplicação financeira de linha de comando desenvolvida em Python como projeto pessoal de estudo.

O objetivo principal é explorar a **Programação Orientada a Objetos (POO)** e entender como aplicar esses conceitos em uma aplicação real.

Este é meu primeiro projeto feito de forma independente, então o foco é aprender, praticar e evoluir ao longo do caminho.

## ✨ Funcionalidades

- [x] Criação de conta
- [x] Depósito
- [x] Saque
- [x] Consulta de saldo

## 🚧 Em desenvolvimento

- [x] Persistência de dados em JSON
- [ ] Login e autenticação
- [ ] Suporte a múltiplas contas
- [ ] Melhor validação de entradas

## 🛠️ Tecnologias

- Python
- Programação Orientada a Objetos (POO)
- JSON

## ▶️ Como executar

Clone o repositório:

```bash
git clone https://github.com/DEVkaionasci/Finance_CLI.git
```

Entre na pasta do projeto:

```bash
cd Finance_CLI
```

Execute o programa (requer Python 3 instalado):

```bash
python main.py
```
